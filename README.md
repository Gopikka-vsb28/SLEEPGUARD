# 🛡️ SLEEPGUARD
### Smart Anti-Drowsiness Jacket for Cyclists

**Live Website Demo:** [Click here to open SLEEPGUARD](https://sleepguard-vb6my3mdtjxwqlfihn2ope.streamlit.app/)

## About the Project
SLEEPGUARD is a software prototype that demonstrates a multi-stage alert system for possible rider drowsiness using simulated sensor inputs.

## Features
- Simulated eye-closure monitoring
- Head-movement index simulation
- Normal, Warning and Critical status
- Multi-stage alert demonstration
- Alert history and movement monitoring

## Technologies Used
- Python
- Streamlit
- Pandas
- GitHub
- Streamlit Community Cloud

## How to Test
1. Open the live website using the link above.
2. Adjust the eye-closure and movement sliders.
3. Click **Check Rider Status**.
4. Observe the status and alert history.

**Note:** This is a software-only demo. Sensor values are simulated; real hardware is not connected.
